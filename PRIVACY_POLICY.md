## Introduction

Kazmo Industry ("we," "our," or "us") operates the Patrol Character Generator mobile and web application (the "App"). This Privacy Policy explains how we collect, use, disclose, and safeguard your information when you use our App.

By using the App, you agree to the collection and use of information in accordance with this policy.

---

## Information We Collect

### 1. Personal Information

**Account Information:**
- Email address (used for authentication)
- User ID (automatically generated by Firebase Authentication)
- Password (encrypted and stored securely by Firebase)

**Optional Information:**
- Remember Me preference (stored locally on your device)

### 2. Character Data

**Game Content:**
- Character names, nicknames, and biographical information
- Character attributes, skills, and game statistics
- Deployment history and narrative information
- Equipment and inventory data
- Character modification timestamps

**User-Generated Content:**
- Portrait images (if uploaded by user)
- Custom text entries (trademarks, motivations, backgrounds)

### 3. Technical Information

**Automatically Collected:**
- Device type and operating system
- App version
- Error logs and crash reports (for debugging)
- Firebase-generated analytics (anonymous usage patterns)

**Not Collected:**
- GPS location data
- Device contacts
- Photos/media (except user-selected portraits)
- Microphone or camera access (except when user explicitly uploads portrait)

## Data Storage & Security

### Local Storage (Your Device)

**Hive Database:**
- All character data stored locally in encrypted database
- Remains on your device even when offline
- Not accessible by other apps

**SharedPreferences:**
- Login credentials (if "Remember Me" enabled)
- App settings and preferences

### Cloud Storage (Firebase)

**Firestore Database:**
- Character data synced to Firebase (optional, requires sign-in)
- Data encrypted in transit (HTTPS/TLS)
- Data encrypted at rest
- Isolated by user ID (you can only access your own characters)

**Firebase Storage:**
- Portrait images (if uploaded)
- PDF exports (temporary, for download)
- Organized by user ID folders

**Firebase Authentication:**
- Email and password managed by Firebase
- Industry-standard security practices
- Two-factor authentication available (if enabled by Firebase)

### Security Measures

- All network traffic encrypted with HTTPS/TLS
- Firebase Security Rules prevent unauthorized access
- User data isolated by userId (you cannot see others' characters)
- No payment information stored (app is free)
- Regular security updates
