Assets folder instructions

Place provided background and portrait images here before running the app.

- `assets/images/background.jpg` : place the attached background picture (the painted patrol image) here.
- `assets/images/portraits/` : put user portrait uploads or painted-style placeholders here.
- `assets/images/gear/` : put stylized gear PNGs (layered, transparent) here for the paper-doll system.

Notes:
- The `pubspec.yaml` already references these asset paths. If you choose different filenames, update `pubspec.yaml` accordingly and run `flutter pub get`.
- For quick local testing, you can copy any JPG as `assets/images/background.jpg`.
